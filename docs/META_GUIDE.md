# 단원 메타(유형 분류 + 흔한 실수) 작성 가이드

파일: `src/content/meta/<그룹>.ts` — `export const META: MetaMap = { '<단원id>': { pitfalls: [...], cats: {...} }, ... }`
타입은 `src/content/meta.ts` 의 `UnitMeta`. 담당 그룹의 **모든 단원**을 채운다 (`src/content/index.ts` 의 GROUPS 참고).

## cats — 유형 분류
단원의 모든 유형(skill id) 각각을 하나로 분류 (빠짐·추가 없이):
- `calc` 연산: 식·수를 계산하는 드릴 (계산하기, 방정식 풀기, 미분하기, 값 구하기 …)
- `concept` 개념: 정의·성질·용어·참/거짓·그림 읽기로 개념 이해를 확인 (옳은 것 고르기, 이름 고르기, 분류, 그래프 모양 고르기, 성질 이용 …)
- `word` 문장제: 일상 상황을 수학 식으로 옮겨야 하는 문제 (사람·물건·돈·거리·시간 이야기)
판단은 생성기 코드와 실제 출력(`npx vite-node scripts/verify-dump.ts -- <단원id> 1`)을 보고 한다. 섞여 있으면 더 많이 나오는 쪽.

## pitfalls — 흔한 실수 2~3개
그 단원에서 학생이 실제로 자주 하는 실수. 한 항목은 한두 문장, 160자 이내, **"실수 → 바른 생각"** 이 드러나게.
- 예(분수의 덧셈): `분모끼리도 더해 버려요: $\frac{1}{2}+\frac{1}{3}\ne\frac{2}{5}$ → 먼저 통분해서 분모를 같게 만든 뒤 분자만 더해요.`
- 예(이차방정식): `양변을 $x$ 로 나눠 버려 $x=0$ 인 근을 잃어요 → 이항해서 인수분해하면 근을 빠뜨리지 않아요.`
- 수식은 `$…$`, 수식 안 한국어는 `\text{}`. 초등은 "~해요" 존댓말로 쉽게, 학년에 맞는 말로.
- 그 단원 개념 카드(`src/content/...`)와 겹치지 않게, 교사가 채점하며 자주 보는 오류 중심.
