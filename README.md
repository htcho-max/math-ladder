# 수학 사다리

초등 1학년 덧셈부터 고등 미적분·기하까지, 2022 개정 교육과정 148개 단원·757개 문제 유형을 **이어지는 개념**으로 배우는 PWA.

- 학습 지도(과정별 / 계통도), 단원마다 먼저 배울 단원·이어지는 단원 연결
- 개념 카드 → 유형별 연습(난이도 1·2·3 자동 조절) → 숙련도
- 단원평가 · 중간고사 · 기말고사 · 범위 직접 선택 · 수준 진단, 시험지 인쇄
- 오답노트(복습 간격 0·1·3·7·14일), 비슷한 문제
- 문제는 규칙 기반 생성기(단원당 4~6유형, 시드로 재생성) — 오프라인 동작
- 오늘의 학습: 하루 목표만큼(기본 20문제) 오답 복습 → 추천 단원 새 문제 → 약한 유형을 한 묶음으로, 중간에 나가도 이어 풀기, 끝내면 도장·+100 XP·달력 기록
- 부모 메뉴 (PIN 잠금): 숫자 4자리 PIN(소금+SHA-256 해시 저장, 5번 틀리면 30초 대기, 확인 질문으로 재설정), 열면 10분 유지. 학습 리포트(최근 7일 푼 문제·정답률·오늘의 학습 완료일·막대 그래프, 지도 팁, 지도가 필요한 단원과 흔한 실수, 자주 틀리는 유형과 실제 틀린 문제·풀이, 달력, 최근 시험)와 설정(오늘의 학습 분량 5~100, 학년·프로필, 문제 형식, 선수 단원 잠금, AI 키, 백업)은 부모 메뉴에서만. 아이 설정 화면에는 테마·꾸미기 스타일·축하 효과·읽어 주기만
- 셈이 친구: 꾸미기에서 고른 기본 표정이 홈 화면에 보이고, 문제 화면에도 셈이가 나와 문제마다 한마디(정답이면 신나고, 틀리면 같이 풀이 보자고 해요). 화면 설정에서 숨길 수 있음. 학년을 바꾸면 오늘의 학습 남은 문제가 새 학년으로 바로 바뀜
- 문장제·활용 문제 189유형 추가(전체 약 946유형 중 약 27%가 문장제). 오늘의 학습 새 문제 4개 중 1개는 문장제
- 심화 도전: 단원 화면에서 처음부터 심화 문제만 10개. v0.10 에서 단원마다 심화 유형 1개(148개) 추가
- 최상위 도전: 단원마다 최상위 문제집·경시 맛보기(고등은 수능 4점·블랙라벨급) 유형 2개씩 296개. 최상위 도전 화면에서만 나오고 일반 연습·오늘의 학습·숙련도에는 안 섞임, 정답 30 XP, 틀린 문제는 오답노트에만 연습은 2문제 연속으로 맞히면 한 단계 어려워짐(기본 → 보통 → 심화)
- 레벨 곡선 완만하게(다음 레벨까지 200·400·600… XP, Lv3 ≈ 1~2일, Lv10 ≈ 3주). 예전 기록은 지금 레벨을 그대로 두고 옮김
- Gemini 기본 모델 gemini-3.5-flash-lite, 모델이 닫혔다는 응답이 오면 안내된 새 모델로 자동으로 바꿔 다시 시도
- 동기 부여: 경험치·레벨·칭호, 연속 학습(얼음으로 하루 쉬어도 유지), 하루 목표, 오늘의 퀘스트 3개, 배지 32개, 단원 별(★1~3), 사다리 보기
- 학습 장치: 쌍둥이 문제 클리닉(틀리면 숫자만 바뀐 같은 유형으로 극복), 3단계 힌트, 연산·개념·문장제 골라 풀기, 단원별 흔한 실수, 디지털 연습장(펜), 수준 진단 통과 단원 자동 인증, 선수 단원 잠금 모드(선택), 문제 읽어 주기, 오프라인 표시
- 셈이 꾸미기: 몸 색 9·모자 10·얼굴 6·손 8·효과 4가지 아이템을 레벨·배지로 해금 (홈 배너의 셈이를 누르면 꾸미기 화면)
- 학년별 자동 테마: 초등(파스텔·둥근 카드·눌리는 버튼·마스코트 "셈이", Jua/나눔고딕), 중등(민트, Do Hyeon/Noto Sans KR), 고등(인디고·차분, IBM Plex Sans KR). 설정 › 꾸미기에서 바꿀 수 있음. 글꼴은 Google Fonts(서비스 워커가 캐시)
- 선택: Gemini API 키를 설정에 넣으면 AI 선생님 해설·단원 개념 튜터 대화·AI 서술형 문항

## 개발
```
npm install
npm run dev          # http://localhost:5173 (같은 Wi-Fi 휴대폰은 http://PC-IP:5173)
npm test             # 전 단원 생성기 검사 + 핵심 테스트
npm run build        # dist/
npm run build:demo   # dist-demo/index.html (한 파일)
npx vite-node scripts/verify-dump.ts -- m1a 2   # 문제 견본 출력
```
콘텐츠 작성 규칙: `docs/CONTENT_GUIDE.md`. 구조: `src/core`(타입·난수·분수·그림·채점·교육과정), `src/content`(단원별 개념·생성기), `src/lib`(저장·숙련도·시험·AI), `src/pages`, `src/ui`.
